### [Argus, Parking Operations Intelligence](https://argu.live)
**B2B SaaS. Sole developer. Live.**

A real-time intelligence platform for parking facilities. It ingests live sensor data over MQTT, stores it in TimescaleDB hypertables, detects anomalies with Isolation Forest, and forecasts occupancy with Prophet, all pushed to a dashboard over WebSocket.

I built and deployed it solo: nine Docker services on Oracle Cloud, Nginx and SSL, role-based access, and a 26-test suite.

`Django 5` `FastAPI` `Celery` `TimescaleDB` `MQTT` `WebSocket` `Prophet` `Docker`

### [Agentic IoT Controller](https://agentic-iot-controller.vercel.app/)
**LLM plus real hardware. Live.**

An LLM agent that controls physical hardware through plain language. Tell it the room is too hot and it reads live ESP32 sensor data, reasons over it, and flips a real relay that switches a fan.

A genuine feedback loop between a language model and the physical world, with tool calling, memory, guardrails, and voice control.

`FastAPI` `Groq LLM` `ESP32` `MicroPython` `JWT` `React`

### [AI Voice Cloning for IVR](https://github.com/yawar2518/ivr-voice-cloning)
**Self-hosted TTS. Backend and AI engineer.**

Replaces the voice actor and studio loop for business phone systems. Clone a voice once, then generate unlimited IVR prompts from a dashboard. Self-hosted Chatterbox TTS on GPU, a seven-state approval workflow, and EBU R128 audio quality gates before anything goes live.

I co-authored a formal API contract with the frontend engineer before we wrote a line of code.

`Django` `FastAPI` `Celery` `PyTorch` `Chatterbox` `FFmpeg` `S3` `Docker`
